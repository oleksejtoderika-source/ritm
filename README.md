# Ритм

Приложение для iPhone: напоминает о каждом действии в выбранное время, по дням недели или в конкретный день.

- **Сегодня**: план на день, ближайшее действие, отметки «готово».
- **Расписание**: все действия, время, дни недели или дата.
- **Подсказки**: массаж лица и шеи по шагам с анимацией, холод, зарядка.
- **Напоминание** и **Идеи**: свой текст и время, когда о нём напомнить.

Напоминания приходят обычными уведомлениями iPhone, даже когда приложение закрыто. В уведомлении есть кнопки «Готово», «Через 5 мин» и «Как делать».

## Где взять Ritm.ipa

Каждый push в `main` собирает приложение на облачном Mac (GitHub Actions, `macos-15`).

1. Открой вкладку **Releases** справа на странице репозитория.
2. В последней сборке скачай **Ritm.ipa**.

Собрать заново без изменений: **Actions → iOS .ipa (AltServer) → Run workflow**.

## Установка через AltServer (Windows)

Нужны iTunes и iCloud с сайта Apple (не из Microsoft Store) и AltServer.

1. Положи `Ritm.ipa` в `C:\Users\Public\`. Если в пути есть кириллица, AltServer пишет «The app could not be found».
2. Подключи iPhone кабелем и запусти AltServer.
3. Shift + клик по иконке AltServer в трее → **Sideload .ipa**.
4. Выбери iPhone, затем `C:\Users\Public\Ritm.ipa`.
5. При первом запуске разреши уведомления.

С бесплатным Apple ID приложение работает 7 дней. AltStore продлевает его сам, если AltServer запущен и телефон в той же Wi‑Fi сети. Одновременно можно держать не больше 3 таких приложений, включая сам AltStore.

## Разработка

```
npm install
npm run build
npx cap sync ios
```

Веб-версию можно открыть в браузере: после `npm run build` открой `www/index.html`. Там напоминания срабатывают, пока страница открыта.
